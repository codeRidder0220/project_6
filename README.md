# Drag & Drop Image Upload

A simple **Drag & Drop Image Upload** project built using **HTML, CSS, and JavaScript**. Users can either select an image using the file picker or drag and drop an image into the upload area to instantly preview it.

##  Features

*  Upload image using the file picker
*  Drag & Drop image support
*  Instant image preview
*  Clean and responsive UI
*  No external libraries used (Pure JavaScript)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Drag-Drop-Image-Upload/
│── index.html
│── style.css
│── script.js
└── images/
```

##  How It Works

1. Open the project in your browser.
2. Click the upload area and choose an image **or** drag an image into the drop area.
3. The selected image is instantly displayed as a preview.

## JavaScript Concepts Used

* DOM Manipulation
* Event Listeners
* `change` Event
* `dragover` Event
* `drop` Event
* `preventDefault()`
* `URL.createObjectURL()`
* File API (`input.files`)
* Drag & Drop API (`dataTransfer.files`)
